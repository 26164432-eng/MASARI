# مَساري | MASARI

منصة عربية خفيفة لتنظيم الحياة الجامعية، مبنية بـ HTML + CSS + JavaScript فقط.

## المزايا
- لوحة رئيسية وإحصائيات.
- جدول محاضرات أسبوعي.
- إدارة المهام والتكليفات.
- الاختبارات القادمة.
- ملاحظات دراسية.
- حاسبة معدل 4.00.
- حفظ البيانات محليًا باستخدام LocalStorage.
- تصميم متجاوب للهاتف والكمبيوتر.
- لا تحتاج إلى خادم أو قاعدة بيانات للإصدار الأول.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## النشر
المشروع مناسب لـ GitHub Pages لأنه موقع Static بالكامل.


## النشر التلقائي عبر GitHub Pages
ملف سير العمل `.github/workflows/deploy.yml` ينشر الموقع عند الدفع إلى الفرع `main` أو عند تشغيل Workflow يدويًا. بعد رفع المشروع إلى مستودع GitHub، افتح Settings → Pages وتأكد أن النشر عبر GitHub Actions متاح.
